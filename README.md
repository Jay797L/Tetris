# Tetris (s21_brick_game)

Реализация классической игры **Тетрис** на языке C в архитектурном стиле **brick-game** с разделением логики (backend) и отображения (frontend). Проект в рамках **School 21 / C_Bootcamp**.

## О проекте

Игра построена с чётким разделением уровней: вся игровая логика изолирована от графического интерфейса. Взаимодействие между ними происходит через стандартный контракт brick-game API: `userInput()` и `updateCurrentState()`. Логика построена на конечном автомате (FSM). Интерфейс — консольный на базе `ncurses`.

## Игровая логика

- **Поле:** 20 × 10 клеток.
- **7 тетрамино** (I, L, J, O, S, T, Z) — в коде: `ALPHA`…`ZETA`.
- **7-bag рандомизатор** — справедливое распределение фигур через перетасованный мешок из 35 элементов.
- **Ghost piece** — полупрозрачный предпросмотр точки приземления фигуры.
- **Система очков** — растёт с числом одновременно убранных линий.
- **Уровни и скорость** — уровень повышается с набором очков, интервал автопадания сокращается.
- **Рекорд** — сохраняется в файле `record.txt`.

## Конечный автомат (FSM)

| Состояние | Поведение |
|---|---|
| **START** | Ожидание `S/s` для начала игры |
| **GAME** | Активная игра: ввод, автопадание, коллизии, уборка линий, очки |
| **PAUSE** | Пауза по `P/p`, возврат в GAME |
| **GAMEOVER** | `S/s` — рестарт, `Q/q` — выход |
| **QUIT** | Очистка и выход в меню |

## Управление

| Клавиша | Действие |
|---|---|
| `S / s` | Начать игру |
| `← / →` | Движение влево / вправо |
| `↓` | Мягкое опускание |
| `Space` | Мгновенное падение |
| `↑` | Поворот |
| `P / p` | Пауза |
| `Q / q` | Выход в меню |

## Сборка и тесты

Из каталога `src`:

```bash
make            # сборка игры (tetris)
make run        # сборка и запуск
make test       # запуск модульных тестов (Check)
make gcov_report # отчёт о покрытии кода (lcov)
make install    # установка в /usr/local/bin
make dist       # сборка архива brick_game-1.0.tar.gz
make dvi        # просмотр документации
make clean      # удаление сборочных файлов
```

Требуется `ncurses` и `Check` (для тестов).
